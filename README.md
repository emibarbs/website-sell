# Digital Agency & Global Web Solutions

Plataforma web profesional, moderna e internacional desarrollada con Python y Flask, estructurada con arquitectura modular escalable, pasarela de pagos segura con Stripe Webhooks, chat en tiempo real y panel de administración con control de roles.

---

## Requisitos Previos (Windows)

Asegúrate de tener instalado en tu equipo con Windows:
1. **Python (versión 3.10 o superior)** — Marca la casilla *"Add Python to PATH"* durante la instalación.
2. **MySQL Server o MariaDB** — Instalado y operando localmente en el puerto `3306`.
3. **Geany** o tu editor de código preferido.
